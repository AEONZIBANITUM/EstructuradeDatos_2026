# EstructuradeDatos_2026

Repositorio de prácticas y entregables de la materia **Estructura de Datos**, correspondiente al ciclo **26-3**.

## Entregable 1 - Proyecto de prueba

Proyecto de consola desarrollado en C# para comprobar la configuración y funcionamiento de:

- Visual Studio Code
- .NET SDK
- Git
- GitHub

El proyecto muestra el mensaje predeterminado:
```
Hello, World!
```

### Compilación

Para compilar el proyecto:

```powershell
dotnet build .\Entregable1_Prueba\Entregable1_Prueba.csproj
```

### Ejecución

Para ejecutar el proyecto:

```powershell
dotnet run --project .\Entregable1_Prueba\Entregable1_Prueba.csproj
```
